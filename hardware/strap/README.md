# WakeBand strap patterns

Both fit the case rev A strap loops (16.6 x 2.2 mm slots, about 50 mm between the loop bars). Print the PDFs at 100% and check the 50 x 20 mm box.

| File | Strap |
| --- | --- |
| wakeband-strap-pattern-rev-a.pdf | Hook-and-loop strap: soft backing wrapped round 16 mm loop tape, hook tab at the tip. Fixed at one case loop, folds back through the other. Sizes S/M/L. |
| wakeband-strap-pattern-rev-b-elastic-buckle.pdf | Two-piece knit tube strap with 3 mm elastic channels along both edges and a 5/8 in side-release buckle under the wrist (magnetic clasp alternative noted). Sizes S/M/L. |
| make_strap_pattern.py, make_strap_pattern_rev_b.py | Generators (reportlab). Edit sizes or lengths and re-run: `python3 make_strap_pattern_rev_b.py out.pdf`. |

Neither strap passes under the case, so the wrist-side charging contacts stay clear and the motor sits on the skin.
